Good questions first

Before you
connect anything.

The product is designed to be understood before it is deployed.

What is included in the download?

Three inbound messaging bot projects for WhatsApp, Instagram, and Facebook, plus shared AI configuration, editable business context, manuals, Windows scripts, tests, and supporting files.

Do I need my own API credentials?

Yes. You supply the AI endpoint configuration and the relevant Meta credentials, account IDs, access tokens, app secret, verify token, and permissions required for the channel you choose.

Does it work immediately after downloading?

No. You need to install prerequisites, configure the AI model and business information, set up the channel, and test the webhook before using it with real conversations.

Do I need a Meta developer account?

For the WhatsApp, Instagram, and Facebook integrations, you need the corresponding Meta app/account setup and permissions described in the included manuals. Requirements vary by channel.

Can I customize the projects?

Yes. The code and configuration are supplied for inspection and adaptation while keeping credentials private.

How do I get support?

Email dewifystores@gmail.com with the channel and setup step. Never send API keys, access tokens, or private `.env` files.

What is the refund policy?

A specific refund policy was not supplied with the product files. Contact dewifystores@gmail.com for the current policy before purchase.
